# Conventions for section agents

Foundation (owned by the Foundation/Hero build; **do not edit**):
`tailwind.config.js`, `src/index.css`, `src/App.jsx`, `src/main.jsx`, `index.html`,
`src/lib/*`, `src/components/{Overlays,Navbar,Hero,Badge,Icons,InlineSvg,SectionDivider,ShaderCanvas}.jsx`.
If you need a change there, report it instead of making it.

## Where your section lives

- One component per section at `src/components/<Name>.jsx`. It **replaces the existing
  stub** of the same name (keep the default export and the file name).
  Names: Problem, Intro, Offline, ThreeCol, HowItWorks, Capabilities, Stats, Terminal,
  EarlyAccess, Faq, Cta, Footer.
- Optional styles in `src/styles/<Name>.css`, imported at the top of the component
  (`import '../styles/<Name>.css'`). Scope every selector under your section's root class
  so files can't collide.
- Section dividers between sections are rendered by `App.jsx`, so don't add them yourself.
  Dividers *inside* a section (e.g. `.problem-divider`) are yours.
- Root element: `<section>` for sections (Footer: `<footer>`). Keep the ids the stubs
  already carry (`intro-rig`, `our-approach`, `early-access`), because the hero buttons link to them.
- Keep the root element's `className` **static**. `src/lib/visibility.js` adds
  `.is-visible` imperatively, and a React className change would wipe it.

## Copy, values, assets

- All text comes from `src/content.js`. Never paste wording from `reference/original-site/index.html`.
- Use `CLONE_SPEC.md` values exactly. Colours: use the CSS vars (`var(--red)`, `var(--paper-dim)`, …)
  or the Tailwind names from `tailwind.config.js` (`text-paper-dim`, `border-border`, `bg-ink`,
  `font-display`, `font-mono`, `font-pixel`) instead of re-typing hex/oklch.
- Breakpoints are **max-width** (desktop-first): Tailwind `xl:` ≤1280, `lg:` ≤1024,
  `tab:` 769–1024, `md:` ≤768. The default Tailwind `sm/md/lg/xl/2xl` screens are replaced.
  Tailwind's `.container` is disabled; `.container` is the spec's (index.css).
- SVGs: `import x from '../svg/<name>.svg?raw'` + `<InlineSvg svg={x} />` (see `src/svg/README.md`).
  Don't hand-edit files in `src/svg/`; they are regenerated by `scripts/extract-svgs.mjs`.
  If you must alter markup (e.g. diagram labels), do it with a string replace in your component.
- Images and fonts: `/assets/...` and `/fonts/...` (served from `public/`).

## Shared building blocks (already in index.css / components)

- Classes: `.container`, `.section-divider`, `.btn-chamfer` + `.btn-red|.btn-dark|.btn-cta|.btn-outline|.btn-ghost`,
  `.badge`, `.mono`, `.mono-label`, `.section-label`, `.section-title`, `.display`, `.display-heavy`,
  `.status`, `.status-dot`, `.blink-dot`, `.blink-dot-sm`, `.grid-bg`.
- `<Badge icon="problem" className="problem-badge">{copy}</Badge>`. Icon keys are in `components/Icons.jsx`.
- Headings: `h1/h2/h3` are globally `font-weight:700` (Chalet faux-bold, spec §0.2). Spans that
  should stay 400 (`.stat-value`, `.faq-question-text`) are spans, so nothing to undo.
- Every `@keyframes` from spec §17 is defined in index.css. Reference them by name; don't redefine them.
- Off-screen pausing: write `.your-section:not(.is-visible) .thing { animation-play-state: paused }`,
  or add the class `pause-offscreen` to the animated element.
- Shaders: `<ShaderCanvas preset="how" />` (shader1) or `preset="headline"` (shader2/3), inside a
  positioned, sized parent. Feed the mouse with `bindShaderMouse(el)` from `src/lib/ditherShader.js`
  (returns a cleanup) on `.how-illustration` / `#early-access`.

## Don'ts

- No scroll-reveal / fade-in animations (spec §0.9, gotcha #7).
- Don't "fix" chamfer-clipped shadows or borders (gotcha #4) or the ticker jump (gotcha #5).
