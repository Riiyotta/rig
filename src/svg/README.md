# Inline SVGs

Generated by `node scripts/extract-svgs.mjs` from `reference/original-site/index.html`
using the byte ranges in `CLONE_ASSETS.json`. `data-astro-cid-*` attributes are stripped;
everything else (classes, ids, SMIL `<animate>`/`<animateMotion>`) is verbatim.
Re-running the script overwrites these files.

Use them as raw strings so the SMIL survives:

```jsx
import eye from '../svg/surveillance-eye.svg?raw'
import InlineSvg from './InlineSvg.jsx'
<InlineSvg svg={eye} />   // display:contents wrapper; the <svg> is the layout child
```
